# Documentação de Entrega — BipSystem 1.0.0

Documentação do BipSystem organizada pelas quatro perguntas de quem recebe o sistema.

1. [Apresentação](00_apresentacao.md): entrega, equipe, itens conhecidos e critérios de aceite
2. [Usar](01_usar.md): perfis, guia rápido, manual com telas, FAQ, glossário e treinamento
3. [Manter](02_manter.md): requisitos, arquitetura C4, ADRs, dados, contratos de API e guia de desenvolvimento
4. [Sustentar](03_sustentar.md): deploy, runbooks, monitoramento, suporte e SLA, backup, segurança e LGPD
5. [Evoluir](04_evoluir.md): dependências, roadmap, changelog, migrações, compatibilidade e regressão

Esta pasta segue o princípio de docs as code: toda mudança no sistema atualiza estes arquivos no mesmo pull request.
